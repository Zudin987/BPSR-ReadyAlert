# BPSR ReadyAlert v1.33.11

## Changes
- Preserve unthrottled final DPS before manual reset, scene reset and confirmed delayed wipe rollover; retain protections for rapid repulls, long fights and ordinary target despawns.
- Finalize timed benchmark runs independently of subsequent game packets, retain correct last damage, archive to Encounter History, and report success only after data and History HTML are saved. Report archive/refresh failures accurately.
- Prevent a benchmark armed during an existing encounter from starting on that encounter's final snapshot.
- Preserve benchmark and player state through Npcap reconnects while discarding stale TCP fragments.
- Recover missing owner identity from verified self-only UID and matching-name packets, without guessing another player's identity.

## Compatibility, validation and limitations
- Windows PR CI exercises unit/regression tests, Clippy, compilation, EXE smoke, size and packaging. An automated smoke test is not interactive gameplay validation.
- No live side-by-side comparison with CN Resonance Logs and ZDPS has been supplied; accuracy parity is not claimed.
- Automatic dungeon-end packet-triggered finalization remains disabled/diagnostic-only because current-game packet/run semantics and scene correlation have not been verified. Existing three-second wipe boundary remains.
- Manual Windows/Npcap, updater error-injection and real-game validation have not been verified. Issue #157 records the waived manual QA scope, and issue #161 records the deferred auto dungeon reset. Neither should be represented as tested or implemented if closed for scope reasons.
