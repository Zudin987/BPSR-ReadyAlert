# BPSR ReadyAlert v1.33.9

## Scope

v1.33.9 adds **diagnostic-only** dungeon flow decoding to help validate the current live game protocol before automatic encounter-finalization is reconsidered.

- Recognizes documented WorldNtf method 23 (`SyncDungeonData`) full protobuf flow state only when a non-zero dungeon `scene_uuid` is present.
- Recognizes documented WorldNtf method 24 (`SyncDungeonDirtyData`) little-endian dirty-container flow deltas, with optional `scene_uuid`.
- Logs sanitized `dungeon-flow-diag` entries containing source, scene/run correlation values, and the named flow state.
- Adds malformed-packet and state-decoding regression tests.

## Safety boundary

This release **does not reset DPS, archive an encounter, or modify wipe/encounter-boundary behavior from dungeon-flow packets**. PR #160's automatic finalization implementation was intentionally not merged because synthetic fixtures and external protocol documentation are not sufficient evidence of live packet timing and correlation.

Use the diagnostics to collect sanitized observations for issue #161 covering successful completion, wipe/revive, boss phase changes, rapid repull, and town delivery. Player identifiers, chat, and secrets should not be included when sharing logs.
