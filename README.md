# BPSR Ready Alert

Windows BPSR companion with **Ready/queue alerts** and an optional **floating chat overlay**.

**Website:** https://zudin987.github.io/projects/readyalert/

## Use

1. Make sure **Npcap** is installed.
2. Download `BPSR-ReadyAlert.exe` from [Releases](https://github.com/Zudin987/BPSR-ReadyAlert/releases/latest).
3. Run it and select Resonance Logs CN if automatic detection misses it.
4. Leave ReadyAlert running in the system tray.
5. Enable **Chat Overlay** from the tray only if you want it.

### Main features

- Matchmaking / Ready Check sound alerts.
- Optional desktop notifications.
- View-only BPSR chat overlay with tabs, filters, keyword sounds, click-through, opacity, and Always on Top.
- One shared Npcap capture for alerts + chat.

ReadyAlert does **not** inject into BPSR, replace game files, or send/automate chat.
